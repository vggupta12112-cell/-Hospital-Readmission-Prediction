# -Hospital-Readmission-Prediction
Machine learning project that predicts 30-day hospital readmission among diabetic patients using Logistic Regression with L2 regularization. Includes data preprocessing, feature encoding, model training, ROC-AUC evaluation, confusion matrix, and performance analysis.
# Hospital Readmission Prediction

## Overview

This project predicts whether a diabetic patient will be readmitted
to the hospital within 30 days using Logistic Regression with L2
regularization.

## Dataset

Dataset:
UCI Diabetes 130-US Hospitals for Years 1999-2008

Target:
- 1 = Readmitted within 30 days
- 0 = Not readmitted within 30 days

## Machine Learning Approach

- Train-test split
- Missing value imputation
- Feature scaling
- One-hot encoding
- Logistic Regression
- L2 regularization

## Evaluation Metrics

- Accuracy
- ROC-AUC
- Precision
- Recall
- Sensitivity
- Specificity
- Confusion Matrix
- ROC Curve
